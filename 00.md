# Cronos AI Agent SDK - Project Summary
The Cronos AI Agent SDK is a **production-ready, protocol-agnostic AI automation toolkit** for Cronos EVM that enables developers to add intelligent automation to any smart contract protocol.

## 🎯 What It Does

Developers can install the SDK via NPM and instantly add AI-powered automation to their dApps:

```typescript
import { SentinelAgentSDK, RiskMonitor } from '@sentinel/ai-agent-sdk';

const sdk = new SentinelAgentSDK({
  network: 'cronos-testnet',
  rpcUrl: 'https://evm-t3.cronos.org',
  privateKey: process.env.AGENT_PRIVATE_KEY
});

await sdk.registerContract('my-vault', {
  address: '0x123...',
  abi: vaultABI,
  network: 'cronos-testnet'
});
```

## 🤖 Agents & Components

### 5 Built-in Agents (Decision-Makers)
- **RiskMonitor**: Prevents unsafe transactions
- **LiquidityOptimizer**: Optimizes liquidity allocation
- **EmergencyBrake**: Triggers emergency stops
- **ThresholdGuard**: Enforces limits
- **AnomalyDetector**: Detects suspicious behavior

**Plus:** 1 example custom agent (GeniusActComplianceAgent) + framework for unlimited custom agents

### 8 SDK Components (Infrastructure)
- **Policy System**: Governance & compliance
- **Control Plane**: Centralized management
- **Payment System (x402)**: Monetization & billing
- **Contract System**: Blockchain integration
- **Event System**: Real-time monitoring
- **API Server**: REST API endpoints
- **AI Integration**: OpenAI support
- **Audit System**: Decision tracking

> **Important:** Agents make recommendations, components provide infrastructure. See [Agents vs Components](./docs/AGENTS_VS_COMPONENTS.md) for details.

## 💳 x402 Payment Standard (Production Ready)

The SDK implements the **HTTP 402 Payment Required** standard for seamless pay-per-use monetization:

### ✅ Ready Out-of-the-Box Features

**Core Payment System:**
- ✅ Automatic 402 error detection and handling
- ✅ Retry logic with exponential backoff (configurable)
- ✅ Payment verification and transaction tracking
- ✅ Usage tracking and billing metrics

**Payment Providers:**
- ✅ **Cronos Network** - Native CRO payments (built-in)
- ✅ **Mobile Wallets** - Apple Pay & Google Pay integration
- ✅ **Enterprise Connectors** - SAP, QuickBooks, Oracle ERP

**Quick Setup:**
```typescript
const sdk = new SentinelAgentSDK({
  network: 'cronos-testnet',
  rpcUrl: 'https://evm-t3.cronos.org',
  privateKey: process.env.PRIVATE_KEY,
  payments: {
    providers: [], // Auto-adds CronosProvider
    retryConfig: { maxAttempts: 3, baseDelay: 1000, maxDelay: 10000 }
  }
});

// Automatic 402 handling - SDK retries payment automatically
const result = await sdk.executeAgent('risk-monitor', context);
```
