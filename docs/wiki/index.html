🎓 Complete Walkthrough: Cronos AI Agent SDK

From Beginner to Expert - Master intelligent automation for smart contracts

🌟 Level 1: What is this?

Think of this SDK as adding a smart brain to your smart contracts. Instead of just executing code, your contracts can now "think" and make intelligent decisions.

❌ Before

Your smart contract is like a vending machine - it just follows simple rules

✅ After

Your smart contract is like a smart assistant that analyzes situations and recommends actions

🏗️ Level 2: Core Architecture

The SDK has 5 main components that work together:

1. CronosAgentSDK

The Main Controller

const sdk = new CronosAgentSDK({
  network: 'cronos-testnet',
  rpcUrl: 'https://evm-t3.cronos.org'
});

2. Agents

The Decision Makers

class RiskMonitor extends BaseAgent {
  async decide(context) {
    if (balance < threshold) return { action: 'BLOCK' };
    return { action: 'ALLOW' };
  }
}

3. Contracts

Your Smart Contracts

await sdk.registerContract('my-vault', {
  address: '0x123...',
  abi: vaultABI
});

4. Events

Blockchain Notifications

sdk.onContractEvent('my-vault', 'Deposited', async (event) => {
  // Someone deposited money - let's analyze it
});

5. Policies

Safety Rules

sdk.addPolicy({
  validate: (decision) => decision.confidence >= 0.7
});

Let's break down how agents actually work:

📥 Agent Input (Context)

const context = {
  contractId: 'my-vault',     // Which contract
  user: '0x123...',           // Which user
  customData: {               // Your specific data
    balance: 5,               // User has 5 tokens
    threshold: 10             // Safe minimum is 10
  }
};

⚙️ Agent Processing

async decide(context) {
  const { balance, threshold } = context.customData;
  
  // Critical risk (25% of threshold)
  if (balance < threshold * 0.25) {
    return {
      action: { type: 'BLOCK', severity: 'CRITICAL' },
      reason: 'Balance critically low',
      confidence: 0.95
    };
  }
  
  // High risk (below threshold)
  if (balance < threshold) {
    return {
      action: { type: 'LIMIT', severity: 'HIGH' },
      reason: 'Balance below threshold',
      confidence: 0.85
    };
  }
  
  // Safe
  return {
    action: { type: 'ALLOW', severity: 'LOW' },
    reason: 'Balance acceptable',
    confidence: 0.9
  };
}

🎨 Level 6: Creating Custom Agents

Here's how to build your own agent:

class PriceProtectionAgent extends BaseAgent {
  config = {
    id: 'price-protection',
    name: 'Price Protection Agent',
    description: 'Prevents price manipulation',
    version: '1.0.0'
  };

  async decide(context: AgentContext): Promise<AgentDecision> {
    // Validate required data
    this.validateContext(context);
    
    const { currentPrice, oraclePrice, maxDeviation = 0.1 } = context.customData;
    
    if (!currentPrice || !oraclePrice) {
      throw new Error('Price data required');
    }

    // Calculate price deviation
    const deviation = Math.abs(currentPrice - oraclePrice) / oraclePrice;

    if (deviation > maxDeviation) {
      return {
        action: { 
          type: 'REJECT', 
          severity: 'HIGH',
          reason: 'Price manipulation detected'
        },
        reason: `Price deviates ${(deviation * 100).toFixed(1)}% from oracle`,
        confidence: 0.95,
        metadata: { deviation, currentPrice, oraclePrice }
      };
    }

    return {
      action: { 
        type: 'APPROVE', 
        severity: 'LOW',
        reason: 'Price within acceptable range'
      },
      reason: `Price deviation ${(deviation * 100).toFixed(1)}% is acceptable`,
      confidence: 0.9,
      metadata: { deviation }
    };
  }
}

// Register and use your custom agent
sdk.registerAgent('price-protection', new PriceProtectionAgent());

🚀 Level 7: Real-World Implementation

Let's build a complete DeFi vault protection system:

import { CronosAgentSDK, RiskMonitor, EmergencyBrake } from '@cronos/ai-agent-sdk';

async function setupVaultProtection() {
  // 1. Initialize SDK
  const sdk = new CronosAgentSDK({
    network: 'cronos-testnet',
    rpcUrl: 'https://evm-t3.cronos.org',
    privateKey: process.env.PRIVATE_KEY
  });

  // 2. Register your vault contract
  await sdk.registerContract('vault', {
    address: '0x123...',
    abi: vaultABI,
    network: 'cronos-testnet'
  });

  // 3. Register protection agents
  sdk.registerAgent('risk-monitor', new RiskMonitor());
  sdk.registerAgent('emergency-brake', new EmergencyBrake());

  // 4. Add safety policies
  sdk.addPolicy({
    id: 'min-confidence',
    validate: (decision) => decision.confidence >= 0.8,
    enforce: (decision) => ({
      ...decision,
      confidence: Math.max(decision.confidence, 0.8)
    })
  });

  // 5. Set up automatic monitoring
  sdk.onContractEvent('vault', 'Deposited', async (event) => {
    console.log(`💰 Deposit: ${event.args.amount} from ${event.args.user}`);

    // Check risk level
    const riskDecision = await sdk.executeAgent('risk-monitor', {
      contractId: 'vault',
      user: event.args.user,
      customData: {
        balance: event.args.newBalance,
        threshold: ethers.parseEther('10')
      }
    });

    // Check system health
    const systemDecision = await sdk.executeAgent('emergency-brake', {
      contractId: 'vault',
      user: event.args.user,
      customData: {
        metric: await getSystemLoad(),
        criticalThreshold: 90
      }
    });

    // Act on decisions
    if (riskDecision.action.type === 'BLOCK' || systemDecision.action.type === 'PAUSE') {
      await pauseUserOperations(event.args.user);
      console.log('🚨 User operations paused due to risk/system issues');
    } else if (riskDecision.action.type === 'LIMIT') {
      await setUserLimits(event.args.user, riskDecision.action.value);
      console.log('⚠️ User limits adjusted based on risk assessment');
    }
  });

  // 6. Start monitoring
  await sdk.start();
  console.log('🛡️ Vault protection system active');
}

💳 Level 11: x402 Payment Integration

The SDK supports HTTP 402 "Payment Required" standard for micropayments and usage-based billing of AI agent services:

📊 What is x402?

HTTP 402 is a status code reserved for future micropayment systems. In the Cronos AI Agent SDK, we implement x402 for:

  • Pay-per-decision: Charge for each agent execution
  • Tiered access: Premium agents require payment
  • Usage metering: Track and bill computational resources
  • Micropayments: Crypto-native payment flows

// Custom payment handler
class CronosPaymentHandler {
  async handlePayment(paymentRequest) {
    const { amount, token, recipient, metadata } = paymentRequest;
    
    // Create payment transaction
    const tx = await this.wallet.sendTransaction({
      to: recipient,
      value: ethers.parseEther(amount),
      data: ethers.utils.hexlify(ethers.utils.toUtf8Bytes(metadata.requestId))
    });
    
    // Wait for confirmation
    const receipt = await tx.wait();
    
    return {
      transactionHash: receipt.transactionHash,
      blockNumber: receipt.blockNumber,
      status: 'confirmed'
    };
  }
}

// Register payment handler
sdk.setPaymentHandler(new CronosPaymentHandler());

// Agent execution with payment flow
sdk.onPaymentRequired(async (paymentRequest) => {
  console.log('Payment required for agent execution:');
  console.log(`Amount: ${paymentRequest.amount} ${paymentRequest.token}`);
  console.log(`Agent: ${paymentRequest.agentId}`);
  
  // Show payment UI or auto-pay
  const confirmed = await showPaymentDialog(paymentRequest);
  if (confirmed) {
    return await sdk.processPayment(paymentRequest);
  }
  throw new Error('Payment cancelled by user');
});

Native blockchain payment integration:

// Web3 payment provider with smart contract integration
class Web3PaymentProvider extends X402PaymentProvider {
  constructor(config) {
    super(config);
    this.paymentContract = new ethers.Contract(
      config.paymentContractAddress,
      paymentABI,
      config.wallet
    );
  }
  
  async createPaymentRequest(agentId, amount, metadata) {
    // Create on-chain payment request
    const tx = await this.paymentContract.createPaymentRequest(
      agentId,
      ethers.parseEther(amount),
      metadata.requestId,
      metadata.expiresAt
    );
    
    const receipt = await tx.wait();
    const requestId = receipt.logs[0].args.requestId;
    
    return {
      requestId,
      amount,
      token: 'CRO',
      recipient: this.paymentContract.address,
      metadata: {
        ...metadata,
        contractRequestId: requestId
      },
      paymentUrl: `cronos://pay/${requestId}`,
      qrCode: await this.generateQRCode(`cronos://pay/${requestId}`)
    };
  }
  
  async verifyPayment(requestId) {
    const payment = await this.paymentContract.getPayment(requestId);
    return {
      paid: payment.status === 'completed',
      transactionHash: payment.txHash,
      timestamp: payment.paidAt
    };
  }
}

  constructor(config) {

      serviceId: agentId,
      quantity: 1,
      unitPrice: this.getAgentPrice(agentId),
      metadata: {
        contractId: context.contractId,
        user: context.user,
        confidence: decision.confidence,
        executionTime: decision.metadata?.executionTime
      }
    };
    
    await this.billingAPI.recordUsage(usageRecord);
  }
  
  async generateMonthlyInvoice(month, year) {
    const usage = await this.billingAPI.getUsage({
      accountId: this.accountId,
      month,
      year
    });
    
    return {
      invoiceId: usage.invoiceId,
      totalAmount: usage.totalAmount,
      currency: 'USD',
      lineItems: usage.services.map(service => ({
        description: `AI Agent: ${service.serviceId}`,
        quantity: service.totalUsage,
        unitPrice: service.unitPrice,
        amount: service.totalAmount
      })),
      paymentDue: new Date(year, month + 1, 15), // 15th of next month
      downloadUrl: usage.invoiceUrl
    };
  }
}
